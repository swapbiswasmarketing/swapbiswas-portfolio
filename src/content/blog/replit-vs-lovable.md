Which builder should a marketer pick when the job is a campaign page, and which when it is an app with logins and a database? That is the real Replit vs Lovable question for anyone who writes briefs for a living and wants to ship the thing too.

**Short answer (as of November 2026):** pick Lovable for a website, landing page or small web app, with one credit balance covering building, hosting and in-app AI. Pick Replit when the app needs logins, a database and back-end work, or a language other than JavaScript. Pick Claude Code when you want to own and run the code yourself.

My view, as a marketer who writes the brief and then builds it: the choice follows from what you are shipping and from how each plan meters usage, not from a same-prompt test. A test tells you which tool had a better afternoon. The billing model tells you what next month costs.

## Replit vs Lovable: Decision Table by Project Type

| What you are shipping | Better fit | Why, from the vendors' own pages |
|---|---|---|
| A campaign page or landing page | Lovable | One credit balance covers building, hosting on Lovable Cloud and AI features ([Lovable pricing](https://lovable.dev/pricing)) |
| A small web app the team will share | Lovable | Workspaces have unlimited members on every plan and no per-seat price ([Lovable plans docs](https://docs.lovable.dev/introduction/subscription-plans)) |
| An MVP with sign-ups, logins and stored data | Replit | Every project includes a pre-configured database, and Replit Auth is built in ([Replit vs Lovable page](https://replit.com/comparisons/replit-vs-lovable)) |
| An internal tool, automation or data pipeline | Replit | Replit says you can build these "in any programming language without setup" (same page) |
| A one-off demo you will throw away | Either free plan | Replit Starter's link lasts 30 days; Lovable Free gets 5 build credits a day, up to 30 a month |
| A site you want to own, host and edit as files | Claude Code | No builder in the loop; see the hub below |

If the last row is you, [Claude Design vs Claude Code](/blog/claude-design-vs-claude-code/) covers where Lovable and Replit sit next to Anthropic's tools. Replit is one of the app builders I use ([my Replit Core pricing guide](/blog/replit-price-in-india/) says so too); this post is written from the two vendors' published pages, not from a side-by-side build.

## Entry Plan Billing: Lovable Pro vs Replit Core

The two entry plans look close on price and work very differently. Every figure below is from the vendors' pages, read on 5 November 2026, in US dollars. Prices and limits change, so check each link before you pay.

Sources: [Lovable pricing](https://lovable.dev/pricing), [Lovable subscription plans](https://docs.lovable.dev/introduction/subscription-plans), [Replit pricing](https://replit.com/pricing), [Replit AI billing docs](https://docs.replit.com/billing/ai-billing), [Replit Starter plan docs](https://docs.replit.com/billing/plans). Replit's pricing page adds that "Prices are subject to tax depending on your location."

Two differences matter most for a marketer's budget:

- **What the money buys.** Lovable's credits pay for three jobs at once: building, running the published app, and AI features inside it. Replit splits the plan into a Free Mode allowance for everyday Agent work and dollar credits for paid modes, which also "cover Agent and other Replit cloud services like published apps, storage, and databases".
- **What you can predict.** Lovable publishes example prompts with their credit cost, so you can estimate a month in prompts. Replit prices paid work by effort and asks before it starts, so the check happens per action rather than up front. Replit publishes no per-prompt figure I could find on these pages, so there is no like-for-like "prompts per dollar" number for the two.

For Lovable's per-prompt examples and how far 100 credits go, [my Lovable vs Bolt billing breakdown](/blog/lovable-vs-bolt/) has the table; I have not repeated it here.

## Free Plans: What You Can Publish on Each

Free plans are where most marketers start, and the publishing rules differ more than the build allowances.

| Free plan rule | Replit Starter | Lovable Free |
|---|---|---|
| Build allowance | Daily Agent credits up to a monthly cap | 5 build credits a day, up to 30 a month |
| What happens at the cap | Credits reset daily, up to the monthly cap | No daily credits for the rest of the calendar month; they resume on the 1st at 00:00 UTC |
| Build depth | Lite build only; Full build needs Core | Daily chat allowance included |
| Published apps | 1, and "This published link will automatically go down after 30 days" | Publish to invited people only, up to 10 people per project |
| Builder badge | "Made with Replit" badge with your referral link | "Edit with Lovable" badge; removal starts at Pro |

Sources: [Replit Starter plan docs](https://docs.replit.com/billing/plans), [Replit AI billing docs](https://docs.replit.com/billing/ai-billing) (the plan table lists "1 (30-day)" published apps on Starter), and [Lovable subscription plans](https://docs.lovable.dev/introduction/subscription-plans).

Lovable's docs give the worked case for the free cap themselves: on Free "you receive daily build credits for the first 6 days each month (6 x 5 = 30), then none until the next month starts".

What this means for a campaign page:

1. **A page that must stay up past a month** needs Replit Core rather than Starter, whose link goes down after 30 days. Lovable's plan docs list no 30-day limit on Free.
2. **A page on your own domain** needs Lovable Pro or above. The Replit plan pages cited here do not list custom domains by plan, so check Replit's custom domain docs before you commit.
3. **A page without the builder's badge** needs a paid plan on either tool.

## Logins, Databases and Teams

For anything beyond a page, these are the published differences:

- **Database and sign-in.** Replit's comparison page says every project includes "a pre-configured, production grade DB" and built-in Replit Auth, and its pricing page lists "Database rollback up to 28 days" on Pro.
- **Teams.** Lovable says workspaces support "unlimited members on all plans" and plans are priced by credits, not seats, with per-member credit limits on Pro and Business. Replit's AI billing table lists 5 collaboration seats on Core and 15 on Pro.
- **Ownership.** Lovable's pricing FAQ answers "Who owns the projects and code?" with "You do."
- **Model choice.** Replit's docs say that in Power or Max modes you can "select Auto to let Replit choose a model for paid work".

## Moving Between Replit and Lovable

You are not locked in by the first choice:

- **Lovable to Replit.** Replit's comparison page carries an "Import app from Lovable" button next to "Get started".
- **Out of Lovable generally.** Lovable lists Git sync with GitHub, GitLab and Bitbucket on every plan, so the code can sit in a repository you control.
- **Out of either into your own stack.** Once the code is in a repository, a coding agent such as Claude Code can take over. My [build notes for this Astro site](/blog/build-a-personal-website-with-claude-code/) show that route end to end.

## Replit vs Lovable Is a Question About What You Ship

The choice gets easier once you name the output. A campaign page or a light web app fits Lovable's single credit balance, where hosting and building draw from the same pool. An app with logins, stored data or a non-JavaScript back end fits Replit's built-in database and auth, with Free Mode for everyday work and credits for paid runs. Read each plan's metering line before the feature list, because that line decides next month's bill. Then re-check both pricing pages on the day you pay, because prices and limits change.
